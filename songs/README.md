# Songs

Every song is a standalone JSON file conforming to the `schemaVersion: 1` schema.

Songs in this catalog are backing tracks only: chord comping and bass may be included, but melodies and lyrics must not be added.

The project is intended for personal and non-commercial educational use. That intended use does not grant rights to distribute third-party material: do not add a chart to this public directory unless its distribution is authorized.

Do not add transcriptions, lyrics, or arrangements of copyrighted works without a license or permission allowing distribution. Always declare the `license` field and retain proof of permission when applicable.

For a non-original work, include a `source` object with its title, URL, and source-license note. The Strudel arrangement must be original unless the source arrangement has an explicitly compatible license.
